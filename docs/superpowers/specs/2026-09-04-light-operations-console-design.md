# QualityFlow 浅色正式控制台设计

## 目标

把现有深色单页控制台升级为可长期使用的浅色测试运营平台，同时保留所有 API、Run 创建、状态查询、结果详情与 Artifact 下载能力。

## 已确认的视觉方向

- 采用用户确认的 A 方案：浅灰画布、白色内容模块、科技蓝主色、绿色成功状态。
- 提高正文、表格和辅助文字对比度，避免浅色页面出现“字融进背景”。
- 侧栏按“工作台、测试执行、平台管理”分组，使用统一线性 SVG 图标。
- 控制圆角和阴影强度，保持企业后台的紧凑感，不做夸张大屏或玩具化卡片。

## 信息架构

1. **运行概览**：关键指标、平台状态和最近 Run。
2. **运行任务**：完整筛选表格及详情入口。
3. **创建测试**：测试类型、注册套件、白名单参数、JSON 编辑和执行摘要。
4. **套件目录**：展示已注册套件、Runner、测试类型、参数与请求体能力。
5. **服务状态**：展示 live、ready 检查。
6. **API 文档**：直接进入 FastAPI `/docs`。

没有后端支持的“执行节点、审计日志、用户管理”等栏目不伪造，避免只有外观没有行为。

## 行为与数据

- 继续使用 `/api/v1/suites`、`/api/v1/runs` 和现有 Run 详情接口。
- 同一份 runs 数据驱动概览、最近运行和完整运行表格。
- 同一份 suites 数据驱动筛选器、创建表单和套件目录。
- 所有现有元素 ID 与请求结构保持兼容；仅调整视图组织和渲染函数。

## 响应式与可访问性

- 桌面保持固定侧栏；窄屏把导航改为顶部可换行区域。
- 表格在窄屏横向滚动，不压缩关键文本。
- 所有操作保留可见标签、键盘焦点、44px 最小操作高度。
- 状态同时使用文字和颜色，支持 reduced-motion。

## 验收

- 页面可访问，核心静态资源带新版本号。
- 新增概览、运行任务、套件目录均由真实 API 数据渲染。
- 原有 Run 创建、JSON 校验、详情轮询、Artifact 查看下载和健康检查不回归。
- UI 单元测试、完整单元测试、Ruff、JavaScript 语法与 Compose 配置检查通过。
