# QualityFlow V1 证据矩阵

表中命令必须在所述依赖已准备的隔离环境运行。`GitHub Actions` 行的远程执行证据来自提交 `c06dfc7` 的 [run #4](https://github.com/liuyaohui666/Quality-flow/actions/runs/32014084498)，证据只适用于该提交及表中声明的学生规模边界。

| Claim | Implementation | Verification command | Evidence artifact | Limitation |
| --- | --- | --- | --- | --- |
| 逻辑幂等提交 | `RunService`、PostgreSQL 唯一键、API 冲突回读 | `python -m pytest tests/e2e/test_quality_flow.py::test_duplicate_submission_has_one_effective_attempt_and_terminal_event -q` | 两次 202、同一 run_id、单 Attempt/case/gate/terminal event | 不保证物理 exactly-once |
| Run/Outbox 原子受理 | UoW 中同时写 Run、RunEvent、Outbox | `python -m pytest tests/integration/test_run_persistence.py::test_commit_constraint_failure_rolls_back_run_event_and_outbox -q` | 约束失败后三表均无部分记录 | 依赖真实 PostgreSQL |
| Outbox 恢复 | `OutboxDispatcher`、publish attempts、未确认继续 pending | `python -m pytest tests/unit/test_dispatcher.py -q`；`python -m pytest tests/integration/test_worker_lifecycle.py::test_real_postgres_publish_failure_keeps_outbox_pending_and_counted -q` | 固定 event/run ID、失败后 pending Outbox 与递增 attempts、可见日志 | Redis 非权威；at-least-once |
| 重复 delivery 围栏 | 指定 run_id 条件领取、数据库 Run 状态与 lease | `python -m pytest tests/integration/test_worker_lifecycle.py -k concurrent_duplicate_delivery -q` | 一个有效 Attempt 和一份终态聚合 | 不能证明进程从未物理启动两次 |
| 租约过期恢复与受控重试 | runner/post-run heartbeat CAS、lease token、suite retry snapshot、`LeaseReconciler`、事务内 Outbox | `python -m pytest tests/integration/test_worker_lifecycle.py -k "retry or reconciler or artifact_persistence_failure or blocked_artifact_failure" -q` | Attempt 1 abandoned 后同一 Run 重新排队、唯一 retry event/Outbox、Attempt 2；Artifact 失败保持 `infra_failed/unknown` 且无 retry | 仅显式套件的首次 `worker_lost` 自动重试一次；其他失败不重试；`restful-booker-api` 禁用 |
| 超时分类 | `SafeSubprocessExecutor`、PytestRunner、进程树回收 | `python -m pytest tests/unit/test_subprocess_runner.py -k posix_timeout -q`；`python -m pytest tests/e2e -k slow -q` | `timed_out/unknown`、Linux child-reap 结果、无伪造 JUnit | 受控本地进程，不是恶意代码沙箱 |
| pytest 功能门禁 | JUnit parser、functional gate | `python -m pytest tests/unit/test_pytest_runner.py -q`；`python -m pytest tests/e2e -k registered_demo_scenarios -q` | ok/error case summary、Attempt、gate、JUnit 元数据与最新 Attempt 逐用例查询 | 不公开 CaseResult 任意 details 字段 |
| Locust 性能门禁 | CSV parser、请求数/错误率/P95 policy | `python -m pytest tests/unit/test_locust_runner.py -q`；`python -m pytest tests/e2e -k registered_demo_scenarios -q` | metrics、performance gate、`p95_ms` reason | 单用户、本地靶场；无多节点压测 |
| 声明式接口依赖 | `WorkflowDefinition`、`WorkflowRunner`、字段捕获/注入、清理步骤、功能门禁 | `python -m pytest tests/unit/test_workflow_definition.py tests/unit/test_workflow_runner.py tests/unit/test_demo_target.py -q`；`python -m pytest tests/e2e/test_quality_flow.py::test_dependent_http_workflow_runs_and_cleans_up -q` | create/read/update/read/delete 五个 CaseResult、捕获变量名、脱敏 JSON 报告 | 仅可信顺序 HTTP 工作流；无分支、循环、并行或可视化编排 |
| Agent 应用规则评测 | `AgentEvalDefinition`、`AgentEvalRunner`、工具 allowlist、scope/Token 规则、通用 Metric | `python -m pytest tests/unit/test_agent_eval_definition.py tests/unit/test_agent_eval_runner.py tests/unit/test_runner_metrics.py -q`；`python -m pytest tests/e2e/test_quality_flow.py::test_agent_application_evaluation_persists_cases_metrics_and_report -q` | 三个 Agent CaseResult、通过率/越权率/P95/Token、脱敏 JSON 报告 | 本地确定性 Agent 靶场；无真实模型或语义 judge |
| Artifact 隔离与读取 | staging 验证、`FileArtifactStore`、Attempt namespace、数据库归属检查、API 只读卷 | `python -m pytest tests/unit/test_artifacts.py tests/unit/test_api_console.py tests/unit/test_compose_contract.py -q`；`python -m pytest tests/e2e/test_quality_flow.py::test_duplicate_submission_has_one_effective_attempt_and_terminal_event -q` | 不同 Artifact/Attempt ID、SHA-256、大小/MIME；按 ID 查看/下载相同字节且 API 无 URI/path | 单机 named volume；无删除/GC |
| 注册套件信任边界 | Registry、参数白名单、固定 argv、`shell=False` | `python -m pytest tests/unit/test_suite_registry.py tests/unit/test_subprocess_runner.py -q` | 非法参数/路径/保留参数被拒 | 只隔离可信套件；不是恶意代码安全沙箱 |
| API 最小暴露面 | Pydantic response allowlist、套件目录、Run 历史、最新 Attempt cases | `python -m pytest tests/unit/test_api_runs.py tests/unit/test_api_console.py -q` | 套件无 argv/path；Run/event/case/Artifact 响应无 URI/path/任意 payload | 无认证，限本地回环地址演示 |
| UI-first 使用闭环 | FastAPI 静态控制台、API 轮询、固定 PowerShell 启动入口 | `python -m pytest tests/unit/test_api_console.py tests/unit/test_launcher_contract.py -q`；Compose E2E 后浏览器点验 | 页面创建 Run、查看历史/用例/门禁/事件/文件；启动脚本无 prune/down -v | 轻量单页界面，无 WebSocket、RBAC、取消或手动重试 |
| 套件化业务 JSON | Suite JSON Schema、Run 快照、受控子进程环境变量、Restful Booker fixture | `python -m pytest tests/unit/test_suite_registry.py tests/unit/test_run_service.py tests/unit/test_subprocess_runner.py tests/unit/test_restful_booker_suite.py tests/integration/test_run_persistence.py -q`；浏览器手工提交公开套件 | 页面可编辑/格式化/校验；服务端拒绝非法字段；PostgreSQL 回读原值；子进程收到紧凑 JSON；省略时兼容 YAML 默认值 | 当前只为 Restful Booker 声明业务请求体；公开外部套件不进入必跑 CI；禁止真实秘密 |
| Compose 隔离拓扑 | Dockerfile allowlist、8 服务、非 root、health gates、限额 tmpfs scratch | `python -m pytest tests/unit/test_compose_contract.py tests/unit/test_healthcheck.py -q`；`docker compose -p quality-flow-check config --quiet` | 服务/卷/端口/health 契约；同容器重启后 workspace/staging 为空 | 单主机；镜像未按 digest 锁定 |
| CI 退出码 | `scripts/ci_gate.py` | live stack 上分别执行 `demo-api / ok` 与 `demo-api / error` | `pass=0`、`expected_quality_failure=1` | 非零类别不能全部等同为质量失败 |
| 七场景闭环 | Demo Target、pytest/Locust/Workflow/Agent Eval Runner、API E2E | `$env:QUALITY_FLOW_API_URL='http://127.0.0.1:18000'; python -m pytest tests/e2e -q` | 七组终态、events、case/metrics、gate 及证据报告 | 只验证确定性本地靶场 |
| CI 诊断保留安全 | evidence allowlist + `audit_ci_evidence.py` | `python -m pytest tests/unit/test_ci_evidence_audit.py -q` | safe bundle 通过；secret URL/header/canary/link 被拒且不回显 | 规则扫描不是通用秘密检测平台 |
| GitHub CI | SHA-pinned workflow：quality/integration/e2e | `python -m pytest tests/unit/test_delivery_contracts.py -q`；检查 [GitHub Actions run #4](https://github.com/liuyaohui666/Quality-flow/actions/runs/32014084498) | 三个 Job 全绿；三份经审计的 JUnit/Compose 日志 evidence artifact | 单次托管 Runner 证据不等于生产持续稳定性 |
